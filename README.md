# HomeFit

Eine iOS-orientierte Flutter-App zum Planen und Durchführen individueller Workouts zuhause.

## Enthaltene erste Version

- Equipment-Auswahl
- Persönliche Trainingsziele
- Dynamisch angepasste Workout-Empfehlung
- Trainingsmodus mit Satz-/Pausen-Timer
- Übungsdetails mit Bewegungsdarstellung und Form-Hinweisen
- Lokaler Fortschrittsbereich

## Lokal starten

1. [Flutter installieren](https://docs.flutter.dev/get-started/install)
2. `flutter pub get`
3. Für iOS auf einem Mac: `flutter run`

Für die Veröffentlichung werden ein Apple-Developer-Account, Xcode und App-Store-Assets benötigt. Die Trainingsinhalte dieser Demo ersetzen keine medizinische Beratung.
